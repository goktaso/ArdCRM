# Kaynak Kuralları

Bu klasör kullanıcının sağladığı PDF, tablo, görsel, bağlantı veya dış sistem
belgelerinin envanteri içindir. Ham kaynağın içeriği izinsiz değiştirilmez.

Yeni kaynak eklendiğinde `kaynak-indeksi.md` dosyasına yol, kaynak tipi, tarih
ve hangi kararı desteklediği eklenir.

**Sınır:** gerçek müşteri verisi, bağlantı dizesi, erişim anahtarı veya kişisel veri
içeren kaynak bu klasöre kopyalanmaz; yalnızca konumu ve amacı indekse yazılır.
