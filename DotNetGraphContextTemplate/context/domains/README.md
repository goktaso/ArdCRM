# Domain Notlari

Bir domain tekrar tekrar baglam gerektiriyorsa burada bir dosya acin:

```text
domains/
  kimlik.md
  siparis.md
  envanter.md
  raporlama.md
```

Her domain dosyasi sunlari icermelidir: sorumluluk, giris/cikislar, temel
kurallar, ilgili kod konumlari, bagimliliklar ve dogrulama yontemi. Dosyayi
olusturduktan sonra `../README.md` tablosuna ekleyin.
